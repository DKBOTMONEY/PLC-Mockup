> 1. **Admin** ซึ่งเป็นสิทธิ์ระดับผู้จัดการโรงงาน สามารถดูและจัดการข้อมูลได้ทุกฟังก์ชัน
> 2. **Technician** สำหรับช่างเทคนิคหน้างาน ซึ่งจะโฟกัสที่การรับแจ้งปัญหาและการลงบันทึกซ่อมบำรุงครับ"

**Speaker 2:**
> "ในเชิงความปลอดภัย เราไม่ได้ตรวจสอบสิทธิ์เฉพาะหน้าบ้านเท่านั้น แต่เราใช้แนวคิด **Defense in Depth**:
> 1. หน้าบ้านใช้ **Zod Schema** ตรวจสอบ Format ข้อมูล
> 2. ที่เครือข่ายมี **Next.js Edge Middleware (`middleware.ts`)** คอยดักสกัด JWT Token หากช่างเทคนิคพยายามพิมพ์ URL เพื่อเข้าหน้า Admin ระบบจะดีดกลับทันที
> 3. และชั้นในสุดคือ **PostgreSQL RLS Policies** ที่คุมสิทธิ์ถึงระดับ Row ไม่ว่าใครจะยิง API ตรงก็ไม่สามารถข้ามสิทธิ์ได้ครับ"
